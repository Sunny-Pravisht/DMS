Core endpoints

Full reference
  • POST /api/auth/login Start a session
  • GET /api/documents/ List documents in scope
  • POST /api/documents/upload Capture a file
  • POST /api/search/ Full-text and semantic search
  • POST /api/search/rag Grounded question answering
  • GET /api/documents/{id}/download Retrieve the original file
  • DELETE /api/documents/{id} Delete, blocked under retention or hold

Capture a document

# Authenticate, then upload
curl -X POST https://dms.company.com/api/documents/upload \
  -H "Authorization: Bearer $DMS_KEY" \
  -F "file=@invoice.pdf" \
  -F "department=finance" \
  -F "tags=invoice,q3"

The response returns the document id, the classification the platform assigned, and the retention policy it fell under.
